# AIMi FinLLAMA Dashboard — Next.js Prototype

A professional React/Next.js dashboard for AIMi, designed around the uploaded AIMi SOW, Tier 5 Quant Intelligence spec, PGAGI/GCP architecture, and the visual mockups.

## Includes
- Dark purple FinLLAMA-style UI
- Tier 1–5 feature gating
- Ask AIMi chatbot screen
- Learning Academy / LMS
- Insights and intelligence feed
- Tier 4–5 structured signals
- Tier 5 Regime AI + Portfolio Risk Engine
- Admin portal modules
- Compliance guardrails and audit/replay log view
- Embedded FinLLAMA architecture image
- Mobile-responsive layout

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## Deploy
Deploy directly to Vercel, Netlify, or any Next.js-compatible host.

## Important compliance position
AIMi remains an education and decision-intelligence layer. It does not execute trades, hold client money, manage portfolios, or give personalised financial advice.
